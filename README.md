# Drone_Quadicopter
Modélisation et commande en cascade (PID) d'un quadricoptère ESP-Drone en vol stationnaire sous MATLAB/Simulink. Simulation interactive 3D avec rafales de vent aléatoires, comparaison MATLAB/Simulink et script d'évaluation de la robustesse (erreurs X/Y/Z, seuils 0,15 m / 0,05 m).
